# 发票单据标签与补零规则

发票备注中的`单据号收款`、`单据号收款号`与现有`单据号`、`单据收款号`按同义标签处理。标签后的分隔符、收款前缀、完整字母数字串和日期提取仍按既有规则处理。

11位单据号可按已确认的定向规则删除首个补零段中的一个`0`；没有可删除的`0`时保持无效。10位单据号直接使用，既有定向9位修正、日期唯一性和单据唯一性校验继续生效。无法确认的单据号留空，不增加销售或回款兜底。

通过`InvoiceJob.run`工作簿入口覆盖标签同义词、补零边界、冲突、无效长度和唯一性。完整数据验收每次使用当前输入副本并核对源文件哈希，具体结果见[当前清洗验收](cleaning-validation.md)。
