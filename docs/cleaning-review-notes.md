# 清洗规则已确认决定

本文件只保留跨批次适用的业务决定；输入文件名、商户号和字段结构以[清洗业务规则](cleaning-rules.md)为准。

## 参考号

- 销售摘要中只识别完整、边界独立的11位数字加大写`N`。
- 原样参考号未命中时，可对连续11位数字补`N`；已有其他字母尾缀仅在数字不变且最终精确命中银联权威检索号时才纠正。
- 不拼接摘要片段，不生成宽松长度候选，不增删或替换数字；不同权威值构成歧义时留空并记录。

## 审核终止与退货数量

- 未匹配实际回款的审核终止记录不估算补贴，不计上传状态金额或笔数，也不列入审核失败明细；源记录仍保留在已上传结果底部。
- 审核终止记录如匹配到实际回款，按已回款处理。
- 销售用券退货原单和退单仍按补贴金额正负生成`1`和`-1`数量，不单独清零；成对记录按净额自然抵消。

完整字段映射、排序和输出要求见[清洗业务规则](cleaning-rules.md)。
