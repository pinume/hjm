# Issue Tracker: Local

本项目为独立本地项目，取消与任何远程仓库（如 GitHub）的关联。
所有需求、规格、决策与任务跟踪均在本地完成。不使用 `gh` 或尝试与远程同步。

## 本地规格与任务约定

- **业务与清洗规格**：存放于 `docs/`（如 `docs/cleaning-rules.md`、`docs/cleaning-review-spec.md`）。
- **架构决策**：存放于 `docs/adr/`。
- **任务跟踪**：通过本地 Markdown 任务卡（在 `docs/` 或 `.scratch/issues/`）及 Git 提交历史进行归档。
- **单向/双向决策判定**：在提交与复盘中明确记录关键业务取舍与证据。
