# 财务统筹表已确认决定

本文件保留通用报表口径；具体工作表、字段顺序、格式与计算流程见[报表规则](reporting-rules.md)。

- 最终匹配表以本次清洗后的银联交易为底表，保留全部记录及原顺序；退货、负金额和未匹配上传记录均保留。
- 上传状态按银联检索号精确匹配对应类别的已上传记录。银联备注标记已退货时优先显示已退货；其余按上传状态显示。审核终止保留原值，未匹配记录显示未提交。
- 商品信息先通过银联检索号关联销售用券参考号。唯一且大类、品牌、商品名称完整时，三项整体采用销售数据；缺失、歧义或字段不完整时整体回退到发票关联路径，不逐列拼接。商品名称保留来源中的完整文本。
- 发票号优先保留上传数据中的非空值；号码为空或上传未命中时，按报表规则使用唯一销售单据和发票候选兜底。红冲判断只依发票类型和状态，不从退货状态推断。
- 门店发生表、累计回款表和上传明细按已确认范围保留源记录，不擅自筛选、合并或去重。类别顺序、专属字段、日期金额格式和空值行为见报表规则。

用户后续确认或代码变更如调整上述行为，应同步更新本文件与[报表规则](reporting-rules.md)。
