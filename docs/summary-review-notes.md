# 汇总报表已确认决定

本文件记录报表统计口径。当前工作簿名称、字段、格式与计算细则以[报表规则](reporting-rules.md)为准；不固化任何门店或批次的金额、行数和异常数量。

## 汇总

- 发生额和发生笔数取全部销售用券明细的补贴额与数量净和；退货原单、退单不提前排除。
- 回款及待处理状态取对应类别的已上传明细。审核终止记录只有匹配到实际回款时才计入已回款；未匹配记录不计入上传状态统计。
- 未回款、未上传按已确认的金额和笔数差额公式计算；差额为负时保留负数。
- 比率以未舍入的原始金额计算；分母为零时显示0%，负值和超过100%的比例保留。

## 品类品牌汇总

- 排除备注精确为`退货-原单`或`退货-退单`的销售用券记录；其余按财务大类、品牌和备注状态汇总。
- 状态、金额和数量都取销售用券明细；展示已回款、审核通过未回款、待审核、审核失败、未上传五种状态。
- 标准品类顺序保持不变，新增品类和未列品牌按文本升序追加。冰箱标准品牌顺序包括海信；彩电标准品牌顺序包括华为（终端）。
- 金额与数量同时为零时显示短横线；只有一项为零时仍显示数值。负数保留。

## 明细工作表

- 审核失败明细只列清洗后状态为审核失败的上传记录；未匹配审核终止不转换为审核失败。商品名称和空值排序按报表规则执行。
- 异常回款按粉色标记及对应商户筛选，家电电脑和数码分区保留原始记录；异常参考号排序及标色按报表规则执行。
- 异常发票只列黄色且非粉色记录，按匹配单据号排序，不去重、不合并。
